## Environment variables

See repo-root `.env.example` for the full table. Highlights:

| Variable | Required | Purpose |
| --- | --- | --- |
| `PIXABAY_API_KEY` | For Pixabay cascade | Free key at pixabay.com/api — commonly missing |
| `PEXELS_API_KEY` | For Pexels cascade | Free key at pexels.com/api |
| `DVIDS_API_KEY` | For DVIDS cascade | Free registration at api.dvidshub.net |
| `ANTHROPIC_API_KEY` | **Optional** | Only for `BROLL_VERIFIER=api`; default is Claude Code CLI |
| `BROLL_VERIFIER` | No (default `claude_cli`) | `claude_cli` \| `checkpoint` \| `api` \| `clip_only` \| `heuristic` |

LoC, Wikimedia, Archive.org, and NASA Image Library need no keys.

## Cascade order (stock)

```
wikimedia → loc → dvids → nasa → archive_org → pexels → pixabay
```

When `reference_urls` is present on the shot spec, reference ingest runs **first**
(before this cascade). Decision matrix otherwise unchanged.

## Reference ingest (`reference_urls`)

```json
{
  "shot_id": "BR_042",
  "intent": "…",
  "kind": "establishing",
  "duration_seconds": 4,
  "reference_urls": ["https://www.youtube.com/watch?v=…"]
}
```

Pipeline:

1. Fetch via yt-dlp (pinned in ops docs); fallback og:video / `<video>` scrape.
2. Cache under `data/.cache/broll/refs/<url-hash>/`.
3. PySceneDetect split → CLIP prefilter ranks segments → vision verifier confirms.
4. ffmpeg trim to `duration_seconds`.

Provenance: `license.type = "user_provided"`, `source.url` = original link,
`source_metadata.retrieved_at` ISO timestamp.

### Checkpoint flow (`--ask` / `--pick`)

```bash
python pipeline/broll.py scripts/broll/ref_shot.json --ask
# exit 7 — writes output/broll/<shot_id>_contact_sheet.png + _candidates.json

python pipeline/broll.py scripts/broll/ref_shot.json --pick seg_002
# completes shot → output/broll/<shot_id>.mp4 + .meta.json
```

Exit code **7** = awaiting brain (orchestrator W20 surfaces this).

## Vision verifier backends

- **`claude_cli`** (default): `claude -p … --output-format json` using Claude Code subscription; no API key.
- **`checkpoint`**: contact sheet + candidates.json, exit 7.
- **`api`**: Anthropic HTTP API when `ANTHROPIC_API_KEY` set.
- **`clip_only`**: stricter heuristic threshold (`BROLL_CLIP_ONLY_THRESHOLD`, default 0.45).

Automatic fallback: `claude_cli` → `checkpoint` when CLI missing/unauthenticated.
